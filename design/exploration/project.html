// 02. RÉFÉRENTIEL COMPÉTENCES RNCP38436

Preuve de validation et d'atteinte du niveau de compétences requis pour l'obtention du titre RNCP38436 (Développeur Web - Niveau 5).

BC01: CADRER UN PROJET

  • [C1]

    Rédiger un Cahier Des Charges (CDC) conforme RGPD.

  • [C2]

    Rédiger des spécifications techniques de la solution.

  • [C3]

    Déployer un environnement de travail collaboratif (Git/Kanban).

  • [C4]

    Réaliser une maquette ergonomique et accessible.

  • [C5]

    Modéliser les fonctionnalités et la Base de Données (UML/MCD).

  • [C6]

    Présenter et argumenter les choix techniques devant décideurs.

BC02: DÉVELOPPER UNE SOLUTION

  • [C7]

    Développer le prototype de la solution web.

  • [C8]

    Rédiger le code de la solution en respectant les normes d'accessibilité.

  • [C9]

    Intégrer les différents éléments de la solution web (HTML/CSS/JS).

  • [C10]

    Implémenter la partie Front-End d'une solution web.

  • [C11]

    Implémenter la logique et la base de données (Back-End).

  • [C12]

    Sécuriser les accès via des règles d'authentification solides.

  • [C13]

    Concevoir et exécuter un plan de tests (unitaires/intégration).

  • [C14]

    Déployer l'application web sur un serveur de production.

BC03: ASSURANCE QUALITÉ

  • [C15]

    Rédiger une documentation technique claire et évolutive.

  • [C16]

    Rédiger un manuel utilisateur pour garantir leur autonomie.

  • [C17]

    Monitorer le lancement de la solution (retours d’expérience).

  • [C18]

    Identifier les axes d'amélioration de performances (SEO/Vitesse).

  • [C19]

    Évaluer la qualité d'ergonomie et d’accessibilité (normes WCAG).

  • [C20]

    Argumenter par écrit des propositions d'évolutions correctives.
